This tech-support scam campaign uses web pages that target Japanese speakers. The pages combine encrypted JavaScript with several browser APIs intended to keep victims trapped in the scam experience.

Observed techniques include full-screen locks, keyboard hijacking, Web Worker resource exhaustion and browser-window re-spawning when a victim attempts to close the page.
